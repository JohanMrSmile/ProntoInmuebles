# Technical Performance Skills

## Frontend Optimization
- **Image Optimization**: WebP format, responsive images, lazy loading
- **Bundle Analysis**: Code splitting, tree shaking, dynamic imports
- **Caching Strategy**: Service worker, HTTP caching, CDN optimization
- **Font Loading**: Font-display swap, subset optimization, preloading

## Backend Performance
- **Database Optimization**: Query optimization, indexing, caching layers
- **API Design**: RESTful endpoints, GraphQL for complex queries
- **Server-Side Rendering**: Next.js ISR, SSG for static content
- **CDN Integration**: Global distribution, edge computing

## Monitoring & Analytics
- **Core Web Vitals**: LCP, FID, CLS tracking
- **Real User Monitoring**: Session recordings, error tracking
- **Performance Budgets**: Bundle size limits, image size limits
- **Automated Testing**: Lighthouse CI, performance regression tests
