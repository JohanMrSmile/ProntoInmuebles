# Visual Design Skills

## Design System Architecture
- **Color Palette**: Primary (#1E40AF), Secondary (#059669), Amber (#F59E0B), Slate grays
- **Typography Scale**: Montserrat (600-900) for headings, Inter (400-500) for body
- **Spacing Scale**: 4px base unit (0.25rem, 0.5rem, 0.75rem, 1rem, 1.5rem, etc.)
- **Border Radius**: Consistent rounding (0.5rem, 1rem, 2rem)

## Component Library
- **Buttons**: Primary, Outline, WhatsApp, Ghost variants
- **Cards**: Elevated, Glass, Stats, Property cards
- **Forms**: Input groups, Select dropdowns, Checkboxes with icons
- **Navigation**: Responsive navbar, breadcrumb, footer links

## Visual Hierarchy
- **Typography Scale**: H1 (3.5rem) → H2 (2.5rem) → H3 (1.875rem) → Body (1rem)
- **Color Weight**: Primary actions, secondary actions, muted content
- **Layout Grid**: 12-column system with consistent gutters
- **White Space**: Generous spacing for breathing room
